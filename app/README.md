# App

React + TypeScript + Vite + Tailwind frontend for the Buffer Delay Allocation Engine. Static only;
deployed to Netlify using the root `netlify.toml`.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # output in dist/
npm run lint
```

Routes: `/` (landing), `/console` (operations console), `/journey` (guided walkthrough).
